# 🌿 ArdalesHub

## Plant & Wellbeing Journal

**ArdalesHub** is a modern, responsive editorial website focused on **plant care, home & space, wellbeing, and greener living**.

The project was built with React and designed to provide a clean, calm, editorial-style experience for discovering plant-care articles, exploring topics, and learning about greener living.

### 🔗 Live Website

**https://ardaleshub.netlify.app/**

## 📰 Journal

The main journal is available at:

```text
/blog
```

The journal displays articles from the centralized article dataset:

```text
src/data/articles.js
```

Articles include information such as:

```js
{
  id: 1,
  slug: "beginner-guide-to-indoor-plants",
  title: "A Beginner's Guide to Indoor Plants",
  excerpt: "...",
  category: "Plant Care",
  tags: [
    "Indoor plants",
    "Beginner plant care",
    "Greener living"
  ],
  date: "2025-11-10",
  readTime: "6 min read",
  featured: true,
  image: "https://images.pexels.com/...",
  content: "..."
}
```

This allows the journal listing and individual article pages to work from the same article data.

---

## 🖼️ External Images

ArdalesHub does **not** store the journal images as local files inside the project.

Images are referenced through external URLs.

For example:

```js
image:
  "https://images.pexels.com/photos/3097770/pexels-photo-3097770.jpeg?auto=compress&cs=tinysrgb&w=1200"
```

This approach keeps the repository lightweight and avoids committing large image files to GitHub.

This creates a distinction between broad **categories** and more specific **topics**.

## 🔗 Article URLs

Individual articles use their own slugs.


The article slug is used by `SingleBlog.jsx` to retrieve the correct article from `articles.js`.

## 🧩 Article Data Utilities

The centralized article data file contains reusable helper functions.

### Get an article

```js
getArticleBySlug(slug)
```

Returns an individual article using its slug.

### Get articles by category

```js
getArticlesByCategory(category)
```

Returns articles belonging to a specific category.

### Get articles by tag

```js
getArticlesByTag(tag)
```

Returns articles containing a specific tag.

### Get featured articles

```js
getFeaturedArticles(limit)
```

Returns articles marked as featured.

### Get categories

```js
getAllCategories()
```

Returns the available article categories.

### Get tags

```js
getAllTags()
```

Returns unique article tags.

### Sort articles

```js
getSortedArticles()
```

Returns articles ordered by date, newest first.

### Related articles

```js
getRelatedArticles(currentSlug, limit)
```

Returns related articles while excluding the current article.
